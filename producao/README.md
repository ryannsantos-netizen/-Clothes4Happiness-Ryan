## Módulo Produção

Acompanha as etapas do processo produtivo, desempenho das máquinas e consumo de insumos. Permite identificar gargalos, otimizar a produtividade e garantir o cumprimento dos prazos.
Usuários: Operadores de Produção, Supervisores de Fábrica, Engenheiros de Processos
Sistema: Sistema de Chão de Fábrica
