## Módulo Vendas

Responsável pelo registro de transações comerciais, emissão de notas fiscais e atualização automática do estoque. Contribui para a agilidade no atendimento ao cliente e precisão dos dados de vendas.
Usuários: Vendedores, Operadores de Caixa, Gerentes Comerciais
Sistema: Ponto de Venda (PDV)
